# 热菜

热菜是厨房里最有即时感的部分：热油下锅的声音、调味料被激发出来的香气，以及端上桌时刚刚好的温度。

## 做菜小记

- 先准备好所有食材，再开火，炒菜过程会从容很多。
- 调味可以少量多次加入，给食材留下调整空间。
- 热菜出锅后尽快食用，口感通常在前几分钟最好。

后续可以在这里继续添加独立菜谱页面，并从侧边栏或卡片链接过去。
