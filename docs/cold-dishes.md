# 冷菜

冷菜不只是开胃小菜，也是餐桌上调节节奏的一笔清爽颜色。提前准备好，吃饭时会更轻松。

## 备菜小记

- 绿叶菜焯水后及时过凉，颜色和口感会更好。
- 凉拌汁建议单独保存，食用前再拌，避免食材出水。
- 冷菜的咸味会随着时间变明显，调味时可以略微保守。
